## 1. Настройка Git и репозитория

**Выполненные действия:**

- Создан личный репозиторий на GitHub на основе шаблона
- Освоены базовые команды Git:
  - `git clone` — клонирование репозитория
  - `git add` — добавление файлов в отслеживание
  - `git commit -m "сообщение"` — фиксация изменений
  - `git push` — отправка изменений в удаленный репозиторий
  - `git branch` — создание и переключение между ветками
- Изменения фиксировались регулярно с осмысленными комментариями

**Результат:** Репозиторий настроен, базовые команды Git освоены.
