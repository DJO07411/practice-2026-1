## 🧱 1. Класс `Combattant` (Боец)

Класс описывает любого участника боя (героя или врага).

### Конструктор `__init__`
- `nom` — имя бойца
- `pv` — текущие очки здоровья
- `pv_max` — максимальное здоровье
- `attaque_min`, `attaque_max` — диапазон урона

### Методы класса

| Метод | Что делает |
|-------|-------------|
| `est_vivant()` | Возвращает `True`, если здоровье > 0 |
| `attaquer(cible)` | Наносит случайный урон цели |
| `se_soigner()` | Восстанавливает 10–30 HP (не выше максимума) |
| `afficher_stats()` | Показывает полоску здоровья и текущие HP |
