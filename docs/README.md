# Документация

# Отчёт по проекту «Менеджер задач для ЛК Московского Политеха»

## 1. Цель проекта
Редизайн IT-инфраструктуры университета и внедрение единого менеджера задач для создания современной, удобной цифровой экосистемы.

## 2. Проблематика
- Устаревший интерфейс старого ЛК.
- Несовершенный функционал нового ЛК.
- Разрозненность систем (включая СДО на Moodle).
- Отсутствие единого менеджера задач.

## 3. Актуальность и новизна
- **Импортозамещение:** Moodle не входит в реестр Минцифры РФ — проект предлагает альтернативу для работы в «белом списке».
- **Оптимизация:** интеграция существующих сервисов в единую IT-инфраструктуру.
- **Инновации:** современные инструменты, снижающие сложность эксплуатации.

## 4. Задачи проекта
- Анализ и аудит текущих сервисов.
- Проектирование редизайна инфраструктуры.
- Разработка новых модулей.
- Внедрение готового продукта с возможностью масштабирования.
- *Опционально:* подача заявки на включение экосистемы в реестр Минцифры.

## 5. Ключевые риски
- Игнорирование результата со стороны университета.
- Рост нагрузки на серверную инфраструктуру.
- Кадровые затраты (управляемые при правильном планировании).

## 6. Дорожная карта и график
В презентации представлены плановые сроки выполнения работ (страницы 7–8), включая этапы анализа, проектирования, разработки и внедрения.

## 7. Продуктовый результат
- **Авторизация:** решение проблем безопасного доступа.
- **Редизайн:** обновление стилистики и палитры ЛК.
- **Совместимость:** интеграция ЛК и СДО в единую систему.
- **База данных:** новая структура для эффективного хранения.
- **Оптимизация:** ускорение работы системы.
- **Новые инструменты:** диаграмма Ганта, конструктор курсов, менеджер задач, редизайн календаря.

## 8. Итог
Проект направлен на полное обновление цифровой среды Московского Политеха с учётом требований импортозамещения и удобства пользователей. Командой предложен конкретный продуктовый результат, готовая архитектура и план внедрения.
